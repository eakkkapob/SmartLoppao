เชื่อมต่อไปยัง Google Apps Script Web App (Smart loppao)

ระบบไม่สามารถเปิดใน Iframe ได้

หน้านี้ใช้เวลาโหลดนานผิดปกติ หรือติดข้อจำกัด X-Frame-Options ของ Google Apps Script

คำแนะนำในการตรวจสอบ:
  • ตรวจสอบว่าไฟล์ Code.gs มีการใส่ .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL) แล้ว
  • URL ต้องลงท้ายด้วย /exec เท่านั้น (ห้ามใช้ /dev)
  • หากเบราว์เซอร์บล็อก Third-party Cookies อาจต้องเข้าสู่ระบบ Google อีกครั้ง

แผงควบคุมผู้ดูแลระบบ (Admin Panel)

จัดการระบบงาน ลำดับเมนู ตั้งค่ารูปลักษณ์ Smart loppao และการเชื่อมต่อ Google Apps Script

รายการแอปพลิเคชันทั้งหมด

ลากเครื่องหมาย ⠿ เพื่อสลับลำดับเมนู หรือคลิกปุ่มเพื่อเพิ่มแอปใหม่

ลำดับ ไอคอน / ชื่อระบบ หมวดหมู่ โหมดแสดง สถานะ การจัดการ

สำรองข้อมูลและการนำเข้าคอนฟิก (Backup & Restore)

คุณสามารถ Export คอนฟิกไปเป็นไฟล์ .json เพื่อย้ายไปใช้งานบนเครื่องอื่น หรือ Import ไฟล์เพื่อคืนค่าระบบได้ทันที

คืนค่าเริ่มต้นของระบบ (Reset to Defaults)
ล้างข้อมูลใน localStorage ทั้งหมดและนำค่าเริ่มต้นของ Smart loppao กลับมาใช้
คู่มือการตั้งค่า Google Apps Script Web App ให้แสดงผลใน Iframe

โดยค่าเริ่มต้น Google จะไม่อนุญาตให้ฝัง Web App ใน <iframe> ของเว็บอื่น (ป้องกัน Clickjacking) ดังนั้นคุณต้องตั้งค่าคำสั่ง setXFrameOptionsMode ในโปรเจกต์ Google Apps Script ดังนี้:

function doGet(e) { var output = HtmlService.createHtmlOutputFromFile('index'); // สำคัญที่สุด: ปลดล็อก X-Frame-Options ให้เปิดใน Smart loppao ได้ output.setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL); output.setTitle("Smart loppao App"); output.addMetaTag('viewport', 'width=device-width, initial-scale=1'); return output; }
// โค้ดฝั่ง GAS เพื่อส่งข้อมูลหา Portal function sendToPortal(action, payload) { window.parent.postMessage({ source: 'gas-portal-app', action: action, payload: payload }, '*'); }
ข้อควรจำในการ Deploy Web App:
• ต้องเลือก Deploy > New deployment > Select type: Web App
• Execute as: เลือก Me หรือ User accessing the web app
• Who has access: เลือก Anyone หรือบัญชีองค์กรตามต้องการ
• URL ที่ถูกต้อง: ต้องลงท้ายด้วย /exec เสมอ (ห้ามใช้ /dev)
